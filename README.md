# 🚚 NorthPeak Logistics Website

## Overview

NorthPeak Logistics Website is a full-stack logistics management platform that helps customers track shipments and enables administrators to manage deliveries efficiently. The application is deployed on AWS and follows DevOps best practices for scalability, reliability, and automated deployments.

---

## Tech Stack

### Frontend
- React.js
- HTML5
- CSS3


### Cloud & DevOps
- AWS EC2
- AWS VPC
- AWS ALB
- AWS S3
- AWS SNS
- AWS CloudWatch
- Docker
- Jenkins
- Git & GitHub

---

## Features

- Shipment Tracking
- Delivery Status Updates
- Fleet Management
- Customer Management
- Responsive UI
- Real-Time Notifications
- Monitoring & Logging
- Automated CI/CD Pipeline

## AWS Services Used

| Service | Purpose |
|----------|----------|
| EC2 | Application Hosting |
| VPC | Network Security |
| ALB | Load Balancing |
| S3 | Static File Storage |
| SNS | Notifications |
| CloudWatch | Monitoring & Logs |

---

## CI/CD Workflow

1. Code pushed to GitHub
2. Jenkins triggers build
3. Docker image created
4. Application deployed on EC2
5. CloudWatch monitors application
6. SNS sends alerts and notifications
